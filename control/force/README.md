# Force control 확장 지점

상태: **실행 제어기 미지원**. `controller.main()`은 명시적 오류를 발생시킵니다.
현재 위치 제어 실행을 force 제어로 오인하지 않도록 별도 진입점을 두었습니다.

| 파일 | 입력 → 출력 |
|---|---|
| `force_filter.py` | 이전/현재 6축 wrench, 실제 dt, cutoff Hz → 저역통과된 wrench |
| `safety_limit.py` | 6축 wrench + 힘/토크 norm 제한 → 유효 값 또는 오류 |
| `controller.py` | 제어 실행 요청 → 미구현 오류 |

wrench 순서는 `[Fx, Fy, Fz, Tx, Ty, Tz]`, 단위는 N와 Nm입니다.
필터 입력들은 같은 원점과 좌표계에 있어야 합니다. 필터는 영점 보정, 도구 중량
보상, 센서 TF 변환 또는 지연 보상을 수행하지 않습니다. 한계를 넘는 입력을
조용히 잘라내지 않고 오류로 알립니다. 값 검사 자체는 하드웨어 보호 장치가 아닙니다.

구현 시 센서 바이어스/중력 보상, sensor→TCP 변환, 실제 timestamp 유효성,
드라이버 명령 형식, 보장 가능한 제어 주기, 정지 동작부터 정의합니다.
위치 명령만 가능한 로봇이라면 힘 오차를 위치·속도 목표로 변환하는
admittance 설계가 필요하며, 단순히 제어기 이름을 변경해 사용할 수 없습니다.

순수 수치 함수는 센서 기록 재생과 단위 테스트에 사용할 수 있습니다.
`config/controllers/force.yaml`은 향후 설정을 보관하는 용도이며 동작 지원을 의미하지 않습니다.
